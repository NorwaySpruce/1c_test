# Булатицкий Максим Сергеевич, задача 4

## Решение

Предлагается использовать жадный алгоритм: пройти по всем залам, которые открыты, и чинить ходы только, если функция полезности от починки положительна, и передавать в этот алнгоритм разные функции полезности от починки хода:

- простая детерминированная: стоимость зала, в который перейдем, минус стоимость починки. Не гарантирует большую прибыль, но гарантирует то, что король точно не потеряет деньги. 

- простая стохастическая: стоимость зала, плюс матожидание стоимостей открытых еще не посещенных залов-соседей нового, минус стоимость починки.
## Формат вводных данных
В первой строке ввода передайте 3 числа: количество зал, количество ходов, стоимость дня работы шахты. После этого предайте n чисел - награды за залы. Нулевой зал считается стартовым. Далее передайте m строк, описывающих ходы, в формате id u v, u и v - соединяемые залы в 0-индексации.

## Комплиляция и запуск

```
g++ main.cpp -o main
./main [s|d]
```

Скомпилируйте решение и запустите его из командной строки. При запуске можно передать опциональный параметр - какую функцию полезности вы ходите использовать. s соответствует стохастической, d - детерминированной.
